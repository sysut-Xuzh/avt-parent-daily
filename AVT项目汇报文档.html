1项目概述

AVT（Auditory-Verbal Therapy，听觉口语疗法）家庭康复训练平台，是一款面向听障儿童家庭的数字化康复辅助工具。平台基于 AG Bell Academy 国际标准，将专业治疗师的训练方案转化为家长可在日常生活中执行的微任务，通过 卡通动画示范 + 自然语音引导 + 成长日历追踪 三位一体的方式，帮助听障宝宝在家庭场景中持续进行听觉口语康复训练。

3核心功能一：卡通动画示范

这是本次项目的重点创新功能。针对听障儿童家长"不知道怎么引导"的核心痛点，平台为每条训练任务配备了 2D 平面卡通动画 + 自然母亲语音引导，让家长一看就懂、一学就会。

🎬 动画播放机制

触发方式：每个任务卡片上有绿色播放按钮 ▶️，点击弹出全屏动画弹窗。

媒体自适应：自动检测 URL 后缀，MP4 视频用 <video> 自动播放（静音+循环），PNG 图片做 Ken Burns 缩放效果。

分步引导：底部逐步显示训练步骤（每 2.5 秒推进一步），带编号圆点和进度指示。

🔊 自然语音引导（双通道回退）

第一优先级：预生成的自然母亲语音 MP3（使用 edge-tts 神经网络 TTS，zh-CN-XiaoxiaoNeural 声音，语速 -15%，音调 +8Hz），声音温暖自然，贴近真实母亲说话。

回退方案：MP3 加载失败时自动切换到浏览器 Web Speech API（中文女性声音，语速 0.75，音调 1.15）。

文字同步：说话时顶部显示半透明文字横幅，不遮挡画面。

交互控制：支持语音开关、重播（同步重置视频+语音+步骤）。

4核心功能二：成长日历

成长日历是家长端的可视化追踪核心，让家长一目了然地看到宝宝的康复训练历史和进步轨迹。

📅 月历视图

以周一为起始的 7 列网格，支持月份前后切换。每个日期用马卡龙色系 + emoji 标记四种状态：

🎙️
有录音记录
玫瑰色标记，当天有上传过训练录音
📝
有反馈笔记
天蓝色标记，家长填写了情绪/笔记
✅
全部完成
翡翠色标记，当天任务全部完成
⏳
部分完成
淡紫色标记，当天部分任务已完成

📋 日期详情弹窗

点击任意日期，弹出浮屏卡片，展示当日完整训练记录：

  • SVG 进度环 — 动画填充完成率百分比
  • 任务列表 — 每条任务的状态 emoji（✅已完成 / ⏳待办）
  • 录音播放器 — 内嵌 <audio> 控件，可直接回听当日录音
  • 情绪/笔记 — 显示家长当日填写的情绪标签和文字记录

数据来源：并行请求 3 个 API — 月度汇总（/api/calendar）、日志详情（/api/logs）、录音列表（/api/recordings/list），保证日历数据实时同步。

8下一步规划

  • 扩展动画库 — 从当前 4 条扩展到 32 条全覆盖，为每条 AVT 标准任务制作配套动画
