# AVT 家长端 · 核心功能模块总结（汇报稿）

> 项目：AVT（听觉口语康复）家长端 Web 应用
> 技术栈：Next.js 14（App Router） + TypeScript + Tailwind CSS + framer-motion + recharts + lucide-react
> 数据层：本地 `localStorage`（体验 / 未登录态） + Supabase 云端数据库（真实登录用户）
> 文档日期：2026-08-20

---

## 一、总体说明

本期新增 / 重构三大核心模块，覆盖"学 — 练 — 测"家长康复闭环：

| 模块 | 定位 | 核心对象 | 数据来源 |
| --- | --- | --- | --- |
| 每日学习 | 家长知识获取（百词斩 / 薄荷阅读风格） | 文章 / 书单 / 答疑 | 本地结构化数据 |
| 康复社区 | 家长互助社区（真实用户介入） | 帖子 / 评论 / 点赞收藏 | Supabase 云端（带本地降级） |
| 听力测试 | 孩子听觉能力评估（IT-MAIS 量表） | 题库 / 量表 / 报告 | 本地题库 + 常模算法 |

---

## 二、每日学习模块

> 设计目标：像"百词斩 / 薄荷阅读"一样，让家长每天轻松获取结构化康复知识，并把"专家内容"与"家长答疑"打通。

| # | 功能点 | 说明 | 实现亮点 |
| --- | --- | --- | --- |
| 1 | 顶部搜索栏 | 全局搜索学习资源 | 实时过滤标题 / 标签 / 作者，输入即筛 |
| 2 | 分类导航 Tab | 六大内容分类 | 推荐 · 听觉训练 · 言语矫治 · 语言发展 · 认知沟通 · 心理支持 |
| 3 | 阶段书单横滑 | 按康复阶段推送书单 | 初配期 / 适应期 / 提升期 / 融合期四阶段，水平滑动卡片 |
| 4 | 今日精选 | 当日推荐内容流 | 卡片瀑布呈现，带标签与封面，支持一键进详情 |
| 5 | 内容详情页 | 单篇深度阅读 | 认证徽章 + 三数据卡（推荐度 / 阅读人数 / 答疑数）+ 家长笔记区 |
| 6 | 专家内容体系 | 内容权威性背书 | 每条含 `author` / `authorTitle` / `certified`，认证专家显示 👨‍⚕️ 徽章 |
| 7 | 答疑库注入 | 内容自带答疑 | `QA_LIBRARY` + `enrichItem()` 自动为每篇注入常见问答 |
| 8 | 家长笔记 | 个性化留存 | 阅读页可记录个人笔记，随阅读进度沉淀 |

**关键数据模型**：`LearningItem` 增加 `author / authorTitle / certified / recommendPct / readers / qa` 等字段，由 `ARTICLE_META` 与 `QA_LIBRARY` 经 `enrichItem()` 统一注入。

## 三、康复社区模块

> 设计目标：打造"轻量小红书"式家长互助社区，并打通真实后端，让真实用户可以发帖、互动、跨端可见。

| # | 功能点 | 说明 | 实现亮点 |
| --- | --- | --- | --- |
| 1 | 社区信息流首页 | 动态展示帖子 | 搜索 + 频道筛选 + "只看同阶段" + 悬浮发布按钮 + 积分成长条 |
| 2 | 帖子卡片 | 互动式内容卡 | 蓝标认证、长文折叠、话题标签、已实践标记、负面支持卡 |
| 3 | 帖子详情 | 深度互动页 | 治疗师回复置顶、点赞 / 收藏 / 评论全互动 |
| 4 | 三步发布 | 快速分享 | 选话题 → 写内容 → 加图占位，即时上墙 |
| 5 | 个人主页 | 用户中心 | 头像 / 阶段 / 地点头部 + 三统计卡（发布 / 获赞 / 收藏）+ 三 Tab |
| 6 | 三 Tab 切换 | 我的 / 互动记录 | 我的发布（双列网格）· 我的评论 · 点赞·收藏二级切换 |
| 7 | 真实后端 | Supabase 数据库 | 5 张表 + RLS 行级权限 + 点赞/收藏/评论计数触发器 |
| 8 | 云端 / 本地降级 | 优雅兼容 | 已登录走云端真实数据；未登录 / 未建表自动降级本地演示 |
| 9 | 跨用户共享 | 真实用户介入 | 发帖 / 点赞 / 评论落库，多端多用户实时可见 |
| 10 | 日历联动 | 成长轨迹 | 发帖日期同步成长日历 💬 标记，长期追踪分享习惯 |

**数据库表（Supabase）**：`posts` / `comments` / `likes` / `collects` / `therapist_verifications`，外键指向 `auth.users`，已种子 12 篇演示帖 + 评论。

**服务层**：`src/lib/community-service.ts` 暴露 `getFeed / createPost / toggleLike / toggleFavorite / addComment / getProfileView / getMyPostDates`，统一封装"云端优先、本地兜底"。

## 四、听力测试模块

> 设计目标：依据 AVT 听觉发展 Erber 四级与 IT-MAIS 量表，标准化评估孩子听觉能力，并防作弊、可长期追踪。

| # | 功能点 | 说明 | 实现亮点 |
| --- | --- | --- | --- |
| 1 | 题库规模 | 64 题完整题库 | 察知 14 · 分辨 16 · 识别 18 · 理解 16，覆盖 Erber 四级 |
| 2 | 题型多样化 | 三类计分方式 | `choice`（选择）/ `reaction`（反应量表）/ `imitation`（模仿量表）按题适配 |
| 3 | IT-MAIS 量表 | 0–4 分标准化 | 国际主流婴幼儿听觉行为量表，家长观察打分 |
| 4 | 逐级通过标准 | 阶段解锁机制 | 按康复阶段设通过阈值，未达标不可跳级 |
| 5 | 常模对照 | 结果科学解读 | `getNormComparison()` 对照同龄常模，给出区间定位 |
| 6 | 防干扰遮罩 | 专注听 | 🎧 专注听遮罩，防偷看 / 防作弊，保证作答专注 |
| 7 | 报告与徽章 | 结果可视化 | 关卡分 + 子组得分 + 通过徽章 + 常模对照图 |
| 8 | 成长记录 | 日历标记 | 🎯 测评日同步成长日历，长期追踪听觉进展 |
| 9 | 安全防跳级 | 流程严谨 | 首页明确"不可跳级"，保证评估阶梯完整 |

**评估框架**：Erber 四级（察知 → 分辨 → 识别 → 理解），严格遵循"每题 0–4 分（IT-MAIS）"评分规则。
